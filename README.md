## 🕊️ 写在前面：为什么自己“手搓”「自然Fan」？

我是一名自然码的铁杆粉丝，也是自然码双拼与辅码的长期使用者。

在日常使用中，自然码那种“两键一字、音形兼备、节奏分明”的打字手感，早已融入肌肉记忆。然而长期以来，在 macOS 平台上想要找一款真正顺手、纯粹的自然码输入法，可以说充满妥协：
- **macOS 系统自带输入法**：虽支持自然码双拼，但**完全没有辅助码**，遇到同音字重码频繁翻页，效率大打折扣；
- **手心输入法**：曾经是体验最好的方案，但已彻底停止维护，在新版 macOS 下频现兼容性问题；
- **落格输入法**：优秀但输入逻辑与经典自然码打字习惯差异较大，难以契合老肌肉记忆；
- **小狼毫 / 鼠须管 (Rime)**：自由度高但配置门槛过高，繁琐的 YAML 规则与繁重的折腾成本，让普通用户望而却步。

为了让自己在 Mac 上能有一款趁手、纯粹的输入工具，我索性决定自己动手，**从零“手搓”了这款「自然Fan」输入法**。

### 我们的承诺与初衷：
- **无偿分享**：做它的初衷是自用，现在分享出来给所有依然热爱自然码的朋友们免费使用。
- **纯本地离线，无需联网**：没有网络请求代码，不需要连网，所有词频与自造词全在本地 SQLite 中。
- **零隐私追踪，绝对安全**：不记录、不上传任何击键与输入内容，没有任何后台暗桩。
- **两袖清风**：零广告、零弹窗、零商业捆绑，还输入法一个本来该有的纯净天地。

## ✨ 核心功能与特点

- 🎹 **自然码双拼与辅助码**：遵循自然码 2000 键位布局，两键一字；候选栏右侧显示辅助形码提示，支持加码降重。
- 🔮 **自然码特殊符号支持**：支持以 `o` 开头的自然码符号编码（如 `od` 数学符号、`oz` 图形符号、`of` 标点、`oi`/`os` 序号、`ol` 罗马数字、`oj` 箭头、`oy` 拼音声调、`ox` 希腊字母、`ob`/`ov` 制表符等），无需打开字符面板。
- 🎯 **整句输入与局部修改**：
  - **光标联动动态候选**：移动光标时，候选栏跟随光标仅显示光标左侧编码的匹配结果，便于直接选取前半段词语上屏；
  - **长编码分层展示**：输入 6 键以上时同时提供整句推算和句首词组选项，选择句首词组后剩余拼音自动衔接流转。
- 📝 **词库扩充与管理**：
  - **在线动态造词**：输入时按 `⌃=` 或 `` ` `` 进入造词界面，逐字选取并保存入库；
  - **剪贴板学习**：复制文本后按 `Control + Shift + L` 自动拆分生成自造词；
  - **文本批量导入**：支持导入本地纯文本文件（TXT）批量学习词汇；
  - **低频词清理**：支持清理 30 天未使用的自造词。
- 🔤 **中英文混合输入**：自动匹配常用英文单词并在候选栏中提供选项；单按 `Shift` 键可切换为纯英文直输。
- 🔆 **窗口状态指示**：进入中文状态时，当前活动窗口标题栏上方显示半透明黄色提示框（自然Fan · 中），便于直观确认输入模式。
- 🛡️ **纯本地离线运行**：无网络访问权限，不上传输入数据，无内置广告，词库与记录全部存储于本机 SQLite 数据库。
- 🎨 **界面与外观设置**：提供多种主题、字号与字体选择，支持键盘相邻键纠错。

## 📥 下载与安装

进入本项目 [**Releases**](https://github.com/kinson08/ZiranFan/releases) 页面，下载最新的安装包镜像：

- **macOS 安装包**：`ZiranFan-Installer.dmg` (支持 macOS 12+，兼容 M1/M2/M3/M4 与 Intel 芯片)

### 一键安装步骤
1. 打开下载的 `ZiranFan-Installer.dmg`；
2. 双击运行盘内的 **「一键安装.command」**，脚本会自动将应用部署至 `~/Library/Input Methods/` 并刷新系统缓存；
3. 打开 macOS **「系统设置」** $\rightarrow$ **「键盘」** $\rightarrow$ **「文本输入」** 点击 **「编辑...」**；
4. 点击左下角 `+` 号，在简体中文中选中 **「自然Fan」** 并添加；
5. 按 `Control + Space`（或点击屏幕右上角菜单栏）切换至 **自然Fan** 即可开始使用！

## ⌨️ 常用快捷键

| 快捷键 | 功能操作 |
| :--- | :--- |
| **Space (空格)** | 确认上屏第 1 候选字词 / 长句 |
| **Return (回车)** | 将当前原拼音字母直接上屏 |
| **1 ～ 9 / 0** | 选取对应序号候选（0 对应第 10 候选项） |
| **- / =** 或 **[ / ]** | 候选列表向前 / 向后翻页（同时支持方向键与 PageUp/PageDown） |
| **Shift (单按轻触)** | 快速在 **中文拼音** 与 **英文直输** 之间切换 |
| **Control + .** | 切换 **中文标点** 与 **半角英文标点** |
| **Control + Shift + L** | 自动提取系统剪贴板中的词汇并学习自造词 |
| **Esc** | 清除当前输入的拼音编码 |
| **⌘ + , (状态栏打开)** | 呼出输入法外观与偏好设置面板 |
